# Consensus Layer Updates

Staying informed about the latest updates for Consensus Layer clients is crucial for maintaining a secure and efficient Ethereum network. Here are the primary sources for updates from the major clients:

- **Prysm**
  - Stay updated via their [Twitter](https://twitter.com/prylabs) for the latest news and releases.

- **Lighthouse**
  - Follow [Lighthouse on Twitter](https://twitter.com/sigp_io) for updates and insights.

- **Lodestar**
  - Keep track of Lodestar developments by following their [Twitter](https://twitter.com/lodestar_eth).

- **Teku**
  - For the latest Teku updates, follow their [Twitter](https://twitter.com/Teku_ConsenSys).

- **Nimbus**
  - Nimbus provides updates through their [Twitter](https://twitter.com/ethnimbus) and you can subscribe to their [Newsletter](https://subscribe.nimbus.guide/) for detailed information.

Regularly checking these sources will help ensure that your nodes are running the latest software versions, which is essential for optimal performance and security.
