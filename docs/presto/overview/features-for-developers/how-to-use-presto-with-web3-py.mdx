# How to use Presto with web3.py

1.  Create your rollup ([How to Create a Rollup](../main-functionality/how-to-create-a-rollup.mdx)), open it and get the RPC url ([What Is RPC](what-is-rpc.md))\


    ![RPC Link](../../assets/rpc-link (1).png)

```python
from web3 import Web3

presto = Web3(

        "<L2 RPC URL>"
    )
)
```
